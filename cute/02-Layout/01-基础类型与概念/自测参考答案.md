# 基础类型与概念：自测参考答案

> 对应：[基础类型与概念](README.md#8-本节自测)

> 更新：2026-09-11

## 1. 静态整数与动态整数

`_8` 与 `8` 的数学值和映射语义可以相同，区别在于值何时确定：

- `_8` 是静态整数，其值编码在类型中，编译期已经确定；
- `8` 通常表示动态整数，其值在运行时确定。

静态整数有利于编译期计算、合法性检查和代码优化，但不会改变 Layout 所描述的数学映射。

## 2. rank、depth 和 size

```text
rank((3,(2,4)))  = 2
depth((3,(2,4))) = 2
size((3,(2,4)))  = 3 * 2 * 4 = 24
```

- rank 只统计当前层的直接元素：`3` 和 `(2,4)`；
- depth 统计最深的 tuple 嵌套层数；
- size 是所有叶子整数的乘积。

## 3. Shape 与 Stride 为什么必须 congruent

Shape 与 Stride 必须具有一一对应的 tuple 层级结构：

```text
Shape  = (2,(3,4))
Stride = (1,(2,6))     # congruent
```

每个 Shape 叶子都需要一个对应的 Stride 叶子，才能计算该坐标分量对最终 index 的贡献。

如果二者的 tuple profile 不一致，就无法明确地将每个坐标分量与相应 stride 配对。

## 4. mode-0 最先变化与地址连续

不一定。

mode-0 最先变化只描述逻辑坐标的自然枚举顺序。地址如何变化由 mode-0 的 stride 决定：

```text
stride = 1   地址正向连续
stride > 1   地址跳跃，可能出现空洞
stride = 0   重复访问同一地址，即广播或 alias
stride < 0   地址反向变化
```

因此必须区分：

```text
Shape 决定坐标的自然遍历顺序
Stride 决定最终 index 的变化方式
```

## 5. Layout 为什么能够脱离 Tensor 存在

Layout 本身是一个不拥有数据的整数映射：

```text
Layout: coordinate -> index
```

Tensor 才是数据访问对象：

```text
Tensor = Engine + Layout
tensor(coord) = engine[layout(coord)]
```

其中 Engine 负责保存或引用数据，可以对应指针、数组或寄存器片段等，不应只狭义地理解为某一块物理内存。
