## 练习 1：沿层级取得 sublayout

给定：

```text
a = (4,(3,6)):(1,(4,12))
```

结果：

```cpp
layout<0>(a);    // 4:1
layout<1>(a);    // (3,6):(4,12)
layout<1,0>(a);  // 3:4
layout<1,1>(a);  // 6:12
```

## 练习 2：select 与 take

给定：

```text
a = (2,3,5,7):(1,2,6,30)
```

结果：

```cpp
select<0,2>(a);  // (2,5):(1,6)
select<1,3>(a);  // (3,7):(2,30)
take<0,2>(a);    // (2,3):(1,2)
take<1,3>(a);    // (3,5):(2,6)
```

`take<1,3>` 使用半开区间 `[1,3)`，只选择 mode-1 和 mode-2，不包含 mode-3。

## 练习 3：concatenation

给定：

```text
A = 8:2
B = 4:1
```

拼接结果：

```text
make_layout(A,B) = (8,4):(2,1)
```

前 8 个自然序坐标都位于 mode-1 坐标为 0 的位置：

```text
(0,0), (1,0), ..., (7,0)
```

对应 index：

```text
0,2,4,6,8,10,12,14
```

## 练习 4：单层包装

```text
a
  Layout = 3:1
  rank   = 1
  depth  = 0

make_layout(a)
  Layout = (3):(1)
  rank   = 1
  depth  = 1

make_layout(make_layout(a))
  Layout = ((3)):((1))
  rank   = 1
  depth  = 2
```

## 练习 5：group 与 flatten

给定：

```text
a = (2,3,5,7):(1,2,6,30)
```

结果：

```text
b = group<1,3>(a)
  = (2,(3,5),7):(1,(2,6),30)

c = flatten(b)
  = (2,3,5,7):(1,2,6,30)
```

`a`、`b`、`c` 的叶子 mode 顺序均为：

```text
Shape：  2,3,5,7
Stride： 1,2,6,30
```

`flatten` 只删除层级括号，不合并 mode：

```text
flatten(b)  != 210:1
coalesce(b) == 210:1
```

## 练习 6：flatten 后的 rank

给定：

```text
a = ((2,3),(4,5)):((1,2),(6,24))
```

结果：

```text
flatten(a) = (2,3,4,5):(1,2,6,24)
rank       = 4
depth      = 1
```
