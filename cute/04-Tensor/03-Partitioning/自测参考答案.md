# Tensor Partitioning：自测参考答案

> 对应：[Tensor Partitioning](03-Partitioning.md#14-本节自测)
>
> 更新：2026-09-15

## 1. Partitioning 的组成

tiling 或 composition 先把原坐标重组为适合表达 tile、线程、value 的坐标；slicing 再固定其中一部分坐标，留下当前并行实体负责的 subtensor。

## 2. Inner partition

对于：

```text
tiled_a = (tile, rest)
```

inner partition：

```text
固定 rest
保留 tile
```

典型结果是某个 CTA 的完整 tile。

## 3. Outer partition

outer partition：

```text
固定 tile 内位置
保留 rest
```

典型结果是某个线程在所有 tile 中负责的相同逻辑位置。

## 4. `local_tile` 与 `local_partition`

```text
local_tile：
  当前 CTA 或给定坐标对应哪一个完整 tile？

local_partition：
  按给定线程 Layout，当前线性线程 id 负责哪些元素？
```

## 5. TV Layout 的输入

```text
Thread mode：选择并行线程
Value mode：选择该线程持有的第几个 value
```

Layout 输出目标 Tensor 中的数据逻辑坐标。

## 6. 线程 3 的四个位置

官方 Layout：

```text
((2,4),(2,2)):((8,1),(4,16))
```

线程 3 的自然坐标为 `(1,1)`，base 为：

```text
8*1 + 1*1 = 9
```

四个 value 的贡献为 `0,4,16,20`，所以结果是：

```text
9, 13, 25, 29
```

## 7. Composition 的两层映射

```text
(thread,value)
    --tv_layout-->
目标 Tensor 的逻辑坐标
    --A.layout-->
目标 Engine 的最终 offset
```

## 8. Slicing 是否已经复制数据

没有。`tv(threadIdx.x,_)` 只得到当前线程 values 的 Tensor view。若需要把值实际加载进寄存器 owning Tensor，还要执行相应 copy 或赋值操作。
