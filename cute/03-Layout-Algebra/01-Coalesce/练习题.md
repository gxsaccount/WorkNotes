## A. 基础规则

### 练习 1

手算：

```text
coalesce((2,4):(1,2))
```

写出：

1. 是否能够合并；
2. 合并后的 Layout；
3. 化简前后的标量输出序列。

### 练习 2

手算：

```text
coalesce((4,2):(2,1))
```

解释为什么不能仅根据 `size=8` 判断它等于 `8:1`。

### 练习 3

手算：

```text
coalesce((4,1,3):(2,99,8))
```

特别说明 stride 为 99 的 mode 为什么可以被删除。

### 练习 4

手算：

```text
coalesce((2,3,5):(1,2,6))
```

要求写出每一次二元合并。

## B. 概念辨析

### 练习 5

判断正误并解释：

> 如果一个 Layout 能被 coalesce 成单 mode，那么它一定是单射。

请给出一个反例。

### 练习 6

比较：

```text
L = ((2,3),4):((1,2),6)
```

分别写出：

```text
flatten(L)
coalesce(L)
```

并说明二者为什么不同。

### 练习 7

给定：

```text
L = (2,2):(1,1)
```

回答：

1. 它能否合并？
2. 它是否包含广播？
3. 它是否存在地址别名？
4. 正 stride 是否足以保证单射？

---

## C. By-mode Coalesce

### 练习 8

给定官方示例：

```text
A = (2,(1,6)):(1,(6,2))
```

分别计算：

```cpp
coalesce(A)
coalesce(A, Step<_1,_1>{})
```

解释两个结果为何不同。

### 练习 9

给定：

```text
B = ((2,3),(4,5)):((1,2),(6,24))
```

分别计算：

1. 普通 `coalesce(B)`；
2. 按两个顶层 mode 分别 coalesce 的结果。

## D. 证明与验证

### 练习 10

证明：

```text
(s0,s1):(d0,s0*d0)
```

与：

```text
(s0*s1):d0
```

对所有合法标量输入 `i` 产生相同结果。

### 练习 11

给定：

```text
L = (3,2):(1,4)
```

回答：

1. 能否 coalesce？
2. 写出完整标量输出序列；
3. 如果不能合并，具体在哪个条件上失败？
4. 该 Layout 的像集中是否有空洞？

### 练习 12：写代码验证

任选前三道计算题中的两个 Layout，编写程序逐点检查：

```text
size(result) == size(layout)
result(i) == layout(i)
```

要求在发现不一致时输出具体的 `i`、原值和新值，不能静默忽略错误。
