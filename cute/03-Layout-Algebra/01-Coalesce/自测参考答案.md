## 练习 1

```text
(2,4):(1,2)
```

满足：

```text
d1 = 2 = s0*d0 = 2*1
```

因此：

```text
coalesce((2,4):(1,2)) = 8:1
```

化简前后序列均为：

```text
0,1,2,3,4,5,6,7
```

## 练习 2

```text
(4,2):(2,1)
```

合并条件失败：

```text
d1 = 1
s0*d0 = 4*2 = 8
1 != 8
```

所以结果保持：

```text
(4,2):(2,1)
```

其标量输出序列是：

```text
0,2,4,6,1,3,5,7
```

而 `8:1` 的输出是：

```text
0,1,2,3,4,5,6,7
```

`size` 相同只说明定义域中逻辑位置数量相同，不能保证映射顺序相同。

## 练习 3

原 Layout：

```text
(4,1,3):(2,99,8)
```

删除静态 size-1 mode：

```text
(4,3):(2,8)
```

因为该 mode 坐标永远是 0，其贡献永远为：

```text
0*99 = 0
```

随后：

```text
8 = 4*2
```

所以：

```text
coalesce((4,1,3):(2,99,8)) = 12:2
```

## 练习 4

第一次：

```text
2:1 ++ 3:2 => 6:1
```

因为：

```text
2 = 2*1
```

第二次：

```text
6:1 ++ 5:6 => 30:1
```

因为：

```text
6 = 6*1
```

最终：

```text
coalesce((2,3,5):(1,2,6)) = 30:1
```

## 练习 5

错误。

反例：

```text
L = (4,3):(0,0)
```

它满足：

```text
0 = 4*0
```

因此：

```text
coalesce(L) = 12:0
```

但所有逻辑坐标都映射到 0，所以它不是单射。

## 练习 6

```text
L = ((2,3),4):((1,2),6)
```

`flatten` 只删除括号：

```text
flatten(L) = (2,3,4):(1,2,6)
```

`coalesce` 继续应用合并规则：

```text
(2,3,4):(1,2,6)
-> (6,4):(1,6)
-> 24:1
```

因此：

```text
coalesce(L) = 24:1
```

## 练习 7

```text
L = (2,2):(1,1)
```

1. 不能合并，因为 `1 != 2*1`；
2. 没有 stride-0 广播；
3. 有地址别名，`L(1,0) == L(0,1) == 1`；
4. 正 stride 不足以保证单射。

标量输出序列为：

```text
0,1,1,2
```

## 练习 8

普通 coalesce：

```text
(2,(1,6)):(1,(6,2))
-> (2,1,6):(1,6,2)
-> (2,6):(1,2)
-> 12:1
```

所以：

```text
coalesce(A) = 12:1
```

按两个顶层 mode 分别 coalesce：

```text
mode-0：2:1 -> 2:1
mode-1：(1,6):(6,2) -> 6:2
```

重新拼接：

```text
coalesce(A, Step<_1,_1>{}) = (2,6):(1,2)
```

by-mode 版本保留了两个顶层 mode 的边界，不继续跨边界合并。

## 练习 9

```text
B = ((2,3),(4,5)):((1,2),(6,24))
```

普通 coalesce 先拍平：

```text
(2,3,4,5):(1,2,6,24)
```

所有相邻关系都满足，因此：

```text
coalesce(B) = 120:1
```

按两个顶层 mode 分别 coalesce：

```text
(2,3):(1,2)   -> 6:1
(4,5):(6,24)  -> 20:6
```

重新拼接：

```text
(6,20):(1,6)
```

## 练习 10

令：

```text
c0 = i % s0
c1 = i / s0
```

则：

```text
L(i)
= c0*d0 + c1*(s0*d0)
= (c0 + c1*s0)*d0
```

根据混合进制分解：

```text
i = c0 + c1*s0
```

所以：

```text
L(i) = i*d0
```

这正是：

```text
(s0*s1):d0
```

的映射。

## 练习 11

```text
L = (3,2):(1,4)
```

1. 不能合并；
2. 输出序列为 `0,1,2,4,5,6`；
3. 失败条件是 `d1=4`，但 `s0*d0=3*1=3`；
4. 像集在 `[0,7)` 中缺少 3，所以存在空洞。
